# Vertical slice decisions and conflict register

Earlier project decisions stay in [../DECISIONS.md](../DECISIONS.md) and the Commandfall `DESIGN_DECISIONS.md` (references
such as C6 or R4 below point there). This file records what the vertical slice pack changes or has to reconcile.

Status values: **confirmed** (creator), **existing** (implemented rule, kept), **slice default** (reversible, experimental until
approved), **open** (needs the creator), **resolved** (with the source that settled it).
